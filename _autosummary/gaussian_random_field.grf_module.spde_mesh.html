SPDE mesh for use with the GRF module.

covers(x: ndarray, y: ndarray) → ndarray

Which of the given positions fall on the mesh.

A position off the mesh cannot be projected onto any triangle, which gives an all-zero row in the projector matrix and makes INLA refuse the fit. Positions exactly on a triangle edge do project, so the boundary counts as covered.

Parameters:

  • x (np.ndarray) – Eastings, in the mesh’s own coordinate reference system.

  • y (np.ndarray) – Northings, in the mesh’s own coordinate reference system.

Returns:

Boolean, true where the position falls on the mesh.

Return type:

np.ndarray
